NEXIUM CLIENT - DEADSHOT.IO
--------------------------------------------------

### How to Use
1. Extract the downloaded zip file.
2. Open the main **Nexium** folder.
3. Go inside the **Nexium Client** subfolder.
4. Run the **Nexium Client.exe** file to start the game.

### Custom Skins (Auto-Swapper)
1. Press **[INSERT]** inside the game to open the client menu.
2. Go to the **Auto-Swapper** tab.
3. Choose your weapon, upload your custom `.webp` texture, and restart the client to apply it instantly. it instantly.
